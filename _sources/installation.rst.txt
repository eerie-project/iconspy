Installation
============
conda/mamba (recommended)
-------------------------
To install into an existing environment run:

.. code-block:: bash
    mamba install iconspy

(you can replace `mamba` with `conda` if that's your preferred package manager

pip
---
To install with pip

.. code-block:: bash
   pip install iconspy

From source
-----------
:code:`iconspy` can be downloaded from github. To obtain the source code run the command:
.. code-block:: bash

   git clone https://github.com/eerie-project/iconspy.git

.. code-block:: bash

   cd iconspy
   pip install .
